# Aegis Parity Test Log

In-game test checklist for the Tales of Nostalgia `aegis-stats-parity` server changes.

Open the page at https://talesofnostalgia.github.io/aegis-parity-test-log/, pick a change, test it on the test server with a GM account, then press **Post Working** or **Post Not working**. The button opens a GitHub issue form with the change filled in; add your notes and screenshots and press Create. Every report shows up on the page for everyone.

When a Not working report is fixed, close it as completed and the change shows as "Fixed, retest". Close a report as not planned to leave it out of the count.
