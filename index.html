Aegis Parity Test Log

Every change on the Tales of Nostalgia aegis-stats-parity server branch, in commit order. Each change makes the server behave like the official kRO Aegis server. Open a change, test it in game, then post Working or Not working. Every report is a GitHub issue, so everyone sees all the reports here.

The tests use GM commands such as @item and @str, so you need a GM account on the test server. Posting a report needs a free GitHub account. A green eye on a change means someone has it open right now; for this the page shares only an anonymous browser ID and the number of the change you have open.
